🔐 Privacy Policy

Bewafa Discord Bot - Minecraft SMP Integration

Last Updated: June 2026

Overview

The Bewafa Discord Bot is designed exclusively for the Bewafa Minecraft SMP server and its associated Discord community. This Discord application integrates with DiscordSRV to facilitate seamless communication between Discord and Minecraft environments.

This Privacy Policy outlines what data is collected, how it is used, and the measures taken to protect user privacy.

Data Collected

The application may process the following information:

  • Discord User IDs - Unique identifiers for Discord users
  • Discord Usernames and Display Names - Usernames and nicknames as displayed on Discord
  • Messages - Chat messages sent in configured bridge channels between Discord and Minecraft
  • Minecraft Usernames - Player names associated with Minecraft accounts
  • Registration Data - Account-linking information connecting Discord and Minecraft accounts
⚠️ Important: No other personal information (email addresses, IP addresses, payment information, etc.) is collected beyond what is necessary for account linking and message relay functionality.

Purpose of Data Collection

The collected data is used solely for the following purposes:

  • Relaying messages between Discord and Minecraft servers
  • Storing account-linking information to connect Discord and Minecraft accounts
  • Synchronizing server-related features and functionality between Discord and Minecraft
  • Providing a cohesive experience for server members across both platforms

Data Storage

What is Stored

Only registration data (account-linking information) is stored locally. This data is maintained by DiscordSRV and related plugins to enable the connection between Discord accounts and Minecraft player profiles.

Where Data is Stored

Data is stored on the Bewafa Minecraft SMP server infrastructure. Server administrators have access to this data for management and operational purposes.

Message Handling

Messages are relayed in real-time between Discord and Minecraft and are not permanently stored in a separate database. Messages are displayed as they are sent and then discarded from the relay system.

Data Sharing

Your data is never sold, rented, or shared with third parties.

The only exceptions are:

  • Discord - Your data is shared with Discord as required for the bot to function within their platform
  • Minecraft/Microsoft - Your data is shared with Minecraft servers as required for game integration
  • Server Administrators - Administrators have access to registration data for operational and moderation purposes

AI and Machine Learning

Message content and user data are absolutely NOT used to train artificial intelligence, machine learning models, or any automated systems.

Your messages remain private and are used only for their intended purpose: relaying communication between Discord and Minecraft.

Data Security

While we strive to protect your data, please note that this is a community-run server. The server administrators take reasonable precautions to secure stored data from unauthorized access. However, no system is 100% secure, and we cannot guarantee absolute security.

Your Rights

You have the right to:

  • Request Access - Ask what data is stored about you
  • Request Deletion - Ask for your registration data to be removed
  • Withdraw Consent - Stop using the bot and request data deletion

Changes to This Policy

We may update this Privacy Policy from time to time to reflect changes in our practices, technology, or applicable laws. We will notify users of any significant changes via our Discord server or website.
